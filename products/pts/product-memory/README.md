# Product Memory — PTS

Durable decisions, learnings, and constraints. Written once, never deleted — mark entries SUPERSEDED and add a forward reference instead.

## Directories

| Directory | What goes here |
|---|---|
| `product-decisions/` | PM decisions: scope, prioritization, feature trade-offs |
| `ux-decisions/` | UX decisions: flows, patterns, accessibility choices |
| `architecture-decisions/` | Technical ADRs: stack, API design, data model |
| `technical-debt/` | Logged debt items with context and remediation plan |
| `release-learnings/` | Post-release retrospectives and process improvements |
| `incidents/` | Incident postmortems (SEV-1 and SEV-2 required) |

## File naming

```
{YYYY-MM-DD}-{short-slug}.md

Examples:
  2026-08-16-auth-strategy.md
  2026-09-01-navigation-library-choice.md
```
