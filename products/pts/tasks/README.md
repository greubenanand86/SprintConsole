# PTS Tasks

Individual task files for PTS. Each file is one task.

## Naming

```
PTS-{NNN}-{short-slug}.md
```

## Status

Managed via the Kanban board at `products/pts/kanban.md`.
Drag cards between columns in Obsidian — the markdown updates automatically.

## Creating a task

Use the Obsidian template: `obsidian-templates/task.md`
Or run: `TASK_WRITE_ENABLED=true .claude/hooks/pm-agent.sh`
