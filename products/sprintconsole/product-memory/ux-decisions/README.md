# UX Decisions

User flow, interaction pattern, and accessibility decisions made by the UX Agent or design team.

Write an entry when a non-obvious UX direction is chosen — flows that deviate from convention, accessibility trade-offs, or patterns added to the design system.

## Entry template

```markdown
# {Decision title}

**Date**: {YYYY-MM-DD}
**Status**: Active / Superseded by {filename}
**Affects**: {Component, flow, or page}

## Decision

{What UX pattern or direction was chosen?}

## Rationale

{Why this over the alternatives? User research, accessibility requirement, design system constraint?}

## Accessibility notes

{WCAG criteria satisfied or trade-offs made.}

## What not to do

{Anti-pattern this decision prevents — saves future designers from re-debating it.}
```
