# Product Decisions

Scope, prioritization, and feature trade-off decisions made by the PM or product team.

Write an entry when a significant "what we build and why" decision is made — especially when a reasonable alternative was considered and rejected.

## Entry template

```markdown
# {Decision title}

**Date**: {YYYY-MM-DD}
**Status**: Active / Superseded by {filename}

## Decision

{What was decided in one or two sentences.}

## Context

{What situation or trade-off prompted this decision?}

## Alternatives considered

- {Option A} — rejected because {reason}
- {Option B} — rejected because {reason}

## Consequences

{What does this enable or constrain going forward?}
```
